About this data
  • Source: City of Berkeley restaurant inspection data (download the CSV used here).
  • The file holds one row per facility for its latest inspection only, so past inspections and trends over time aren't in it.
  • Each violation is a yes/no flag in five categories (holding temperature, cooking, personal hygiene, contaminated equipment, unsafe food source), split into major and minor. In this file only two minor categories are ever flagged: improper holding temperature and contaminated equipment. No major violations appear.
  • A few facilities appear on more than one row (Whole Foods on Telegraph three times for the same day, Safeway on Shattuck twice). Those are combined here into one facility using its latest date, with every flag from that date.
  • Some businesses have several permits at one address (e.g. Berkeley Bowl and Andronico's departments), so they appear more than once under the same name.
  • Street names are tidied from the address text (typos like "UNIVESITY", "MLK JR. WAY" vs "M L KING JR WY") so each street groups together. The original address is always shown.
  • "12+ months ago" counts days between the inspection and the data pull date; it is not a statement about any required inspection schedule.
